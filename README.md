# 🎮 Games Arena — Landing Page

A modern and engaging **Gaming Platform Landing Page** built as part of my Front-End Development journey at **Route Academy**.

This project was developed after completing the fundamentals of **Bootstrap**, with the goal of applying what I learned in a project that simulates a real-world client brief.

The main objective was to recreate the provided design as accurately as possible while using **Bootstrap** to build and organize the webpage.

---

## 📌 Project Overview

**Games Arena** is a gaming platform landing page designed to introduce the platform and provide visitors with an engaging overview of its content and team.

The project was based on a provided **UI Mockup**, and the goal was to translate the design into a complete webpage while maintaining its visual structure and layout.

---

## ✨ Features

### 🎮 Gaming Platform Landing Page

* Modern gaming-focused interface
* Multiple organized sections
* Visual content and gaming assets
* Design based on the provided client mockup

### 🧭 Navigation

* Structured navigation bar
* Links to different sections of the landing page
* Responsive navigation using Bootstrap

### 👥 Our Team

* Team member cards
* Organized team presentation
* Hover interaction effects

### 📱 Responsive Design

* Responsive layout using Bootstrap
* Bootstrap grid system
* Components adapted to different screen sizes

### ⭐ Bonus — Team Hover Effect

* Added a visual hover effect to team member cards
* Used CSS visual effects to create a more interactive experience
* Applied `backdrop-filter` to enhance the hover interaction
